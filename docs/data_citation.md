# Data Citation

Please cite the GFSM v1 dataset DOI when using the data:

Waleed, M. (2026). Global Flood Susceptibility Map (GFSM v1): A high resolution (30m) flood susceptibility dataset derived from multi-source Earth observation and geospatial data [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20568218

Also cite the associated manuscript when it becomes available. A manuscript placeholder is included in the README and `CITATION.cff`.

For software and repository citation, use the GitHub repository citation metadata in `CITATION.cff`.
