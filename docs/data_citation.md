# Citation Guide

Please cite both the published paper and the archived dataset when using GFSM v1.

## Paper

Waleed, M., Sajjad, M., Al-Ghamdi, S. G., & Gao, M. (2026). A high-resolution global flood susceptibility dataset derived from multi-source earth observation and geospatial data. *Scientific Data*. https://doi.org/10.1038/s41597-026-08338-1

## Dataset

Waleed, M. (2026). Global Flood Susceptibility Map (GFSM v1): A high resolution (30m) flood susceptibility dataset derived from multi-source Earth observation and geospatial data [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20568218

## Repository

GitHub reads [`CITATION.cff`](../CITATION.cff) to generate the repository's **Cite this repository** panel. Copy-ready BibTeX entries for the paper and dataset are available in [`CITATION.bib`](../CITATION.bib).

When publishing derived products, state the GFSM version, access route (Zenodo or Google Earth Engine), date accessed, and any preprocessing or reclassification applied.
