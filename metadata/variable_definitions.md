# Variable Definitions

GFSM v1 is based on geospatial flood conditioning factors that describe topographic, hydrologic, vegetation, anthropogenic, and rainfall-frequency controls on flood susceptibility.

| Abbreviation | Variable | Description |
| --- | --- | --- |
| DEM | Digital elevation model | Surface elevation used to represent terrain position and broad topographic controls. |
| Slope | Terrain slope | Local slope derived from elevation, relevant to runoff concentration and floodplain flatness. |
| Aspect | Terrain aspect | Downslope orientation derived from elevation. |
| TWI | Topographic Wetness Index | Terrain-derived index describing potential water accumulation. |
| NDVI | Normalized Difference Vegetation Index | Vegetation greenness index used as a land-surface condition proxy. |
| HAND | Height Above Nearest Drainage | Relative height above the drainage network, often associated with floodplain position. |
| DistWB | Distance to water bodies | Distance from mapped water features or drainage-related water bodies. |
| DistRd | Distance to roads | Distance from mapped roads, used as an anthropogenic spatial proxy. |
| RainFq | Rainfall frequency | Frequency metric derived from precipitation observations or products. |

These definitions summarize the public manuscript-level variables. They do not document private preprocessing workflows or downstream flood-risk assessment analyses.
