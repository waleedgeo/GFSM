# Validation Summary

This folder provides compact summary metrics already reported for the GFSM v1 manuscript and dataset release.

The CSV table is intended for quick reference by dataset users and reviewers. It does not include full validation notebooks, private intermediate outputs, or downstream flood-risk assessment analyses.

For interpretation, note that the internal ROC-AUC and AUPRC values describe discrimination against model-derived training labels. The DFO correspondence values provide independent event-based plausibility context, not direct pixel-level inundation validation.
